# Panwar Law Website

Vite React project ready for deployment to Vercel, Netlify, or Cloudflare Pages.

## Local setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Upload this folder to GitHub.
2. Go to Vercel.
3. Add New Project.
4. Import the GitHub repository.
5. Click Deploy.

## Important

- Replace `public/logo.png` with your actual PPC logo file.
- The contact form is visual only. Connect it to Formspree, Netlify Forms, Google Forms, or a backend before relying on it.
- Keep Google Workspace MX records unchanged when connecting the domain.
